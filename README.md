# Library Management System

## 🧾 وصف المشروع
نظام مكتبة رقمي بسيط باستخدام Java والبرمجة الكائنية. يسمح بإدارة الكتب، المستعيرين، وعمليات الإعارة والاسترجاع.

## 🎯 أهداف المشروع
- تطبيق مبادئ OOP: التغليف، الوراثة، الواجهات، تعدد الأشكال
- استخدام واجهة نصية (Console)
- تنظيم الكود داخل مشروع Git ورفعه على GitHub

## 🛠️ كيفية التشغيل
1. افتح المجلد `src` في محرر Java
2. شغل الملف `Main.java`
3. اتبع التعليمات في الواجهة النصية

## 🗂️ هيكل المشروع
- `src/`: يحتوي على الكود المصدري
- `docs/`: يحتوي على التوثيق
- `tests/`: يحتوي على اختبارات الوحدة (إن وجدت)

## 📌 ملاحظات حول التصميم
- يتم حفظ جميع الكتب والمستعيرين في قوائم داخلية
- لا يعتمد على قواعد بيانات (يعمل داخل الذاكرة فقط)
